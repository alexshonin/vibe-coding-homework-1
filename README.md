# ДЗ 1. Консольное меню

Курс «Вайб-кодинг: разработка приложений с помощью AI».

## Запуск

```bash
node homework-1.js
```

Программа показывает меню, читает выбор через `readline`, запрашивает нужные числа, печатает результат и завершается.

```
Выберите задачу:
1 — билетная касса
2 — доставка заказа
3 — лестница
Ваш выбор:
```

Если введён не `1`, `2` или `3`, программа печатает `такой задачи нет`.

## Примеры

```
Ваш выбор: 1
Категория билета: 2
Бюджет: 2300
Категория 2, билет 500 руб., бюджет 2300 руб.: можно купить 4 шт.
```

```
Ваш выбор: 2
Расстояние: 12
Сумма заказа: 2500
Расстояние 12 км, заказ 2500 руб.: доставка 250 руб.
```

```
Ваш выбор: 3
Высота лестницы: 12
Ступень 1
Ступень 2
Ступень 3
Ступень 5
...
Ступень 10
Дальше лестница не построена
Всего построено: 9
```

## Функции

| Функция | Что делает |
| --- | --- |
| `ticketPrice(category)` | `switch`: цена билета 300 / 500 / 900, для другой категории `0` |
| `maxTickets(budget, price)` | `while`: сколько билетов можно купить, без деления и округления |
| `printTicketResult(category, budget)` | печатает чек или `неизвестная категория` |
| `deliveryPrice(distance, total)` | стоимость доставки (бесплатно от 3000 руб. или до 3 км, до 10 км — 200 руб., дальше +25 руб. за км) |
| `printDelivery(distance, total)` | печатает строку о доставке |
| `printSteps(height)` | `for`: ступень 4 пропускается через `continue`, после 10-й — `break` |

Функции, которые считают стоимость или количество, возвращают значение, а печатают его отдельные функции `print...`.

## Крайние случаи

- Бюджет меньше цены билета — `можно купить 0 шт.`
- Неизвестная категория (например, `5` или текст) — `неизвестная категория`.
- Ровно 3 км — доставка бесплатна, ровно 10 км — 200 руб., заказ ровно 3000 руб. — бесплатно.
- Неполный километр после десятого считается как целый: 10.5 км — 225 руб.
- Лестница высотой 10 и меньше строится полностью, сообщение `Дальше лестница не построена` появляется только если высота больше 10.
- Если вместо бюджета, расстояния, суммы или высоты ввести текст или отрицательное число — `нужно ввести число не меньше 0`.
